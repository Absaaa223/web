# Perchero

App para administrar un emprendimiento de ropa (y lo que venga después): inventario con fotos y tallas,
percheros y lugares, ventas que descuentan del inventario, y catálogos en PDF o imagen para compartir.

Todo vive en `index.html`. Está publicada como artefacto de Claude, donde los datos y las fotos se guardan
en la nube y se sincronizan entre dispositivos. Abierta como archivo suelto funciona igual, pero guarda
solo en ese navegador.
